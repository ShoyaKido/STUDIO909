# studio909.jp

STUDIO909合同会社の公式サイトです。GitHub Pagesで公開しています。

## お知らせを追加する

`_data/news.yml` に次の4行を書き足して、コミットするだけです。数分でサイトに反映されます。

```yaml
- date: 2026.10.19
  tag: SNS
  title: ○○様にて△△が掲載されました
  url: https://example.com/
```

- `tag` は `MEDIA` / `SNS` / `EVENT` のどれか
- 表示順は日付で自動的に並ぶので、ファイルのどこに書いてもOK
- 同じ日付が複数あるときは、その中の順番は決まりません

## 選出歴のロゴを追加する

トレーラーの下の黒い帯に並ぶロゴです。

1. ロゴ画像を `awards/` フォルダに入れる（背景が透明なPNGかWebP。周りの余白は切り詰めて、高さ200px程度）
2. `_data/awards.yml` に次の3行を書き足して、コミットする

```yaml
- name: ○○ 2027 Official Selection
  image: xxxx-2027.webp
  scale: 1
```

- `name` はロゴの説明（読み上げ用・画像が出ないときに表示）
- `image` は `awards/` フォルダ内のファイル名
- `scale` は大きさの調整。正方形のロゴは `1`、横長のロゴは `0.75`〜`0.9` くらいにすると見た目が揃う
- 並び順はファイルに書いた順（左→右）
- 今の6つに合わせて、PCは1列、スマホは3つずつ2段になるよう調整しています。数を変えたらスマホでも表示を確認してください

## キャラクターを追加・差し替える

PCで見たとき（画面の幅が1280px以上）だけ、本文の左右の余白にキャラクターの全身が表示されます。場所は「お知らせの右」「開発タイトルの左」「企業情報の右」の3か所で、どのキャラクターがどこに出るか・どの表情かは、ページを開くたびにランダムに変わります。スマホ・タブレットでは表示されず、画像も読み込みません。

1. 画像を `chara/` フォルダに入れる（**透過なし・白背景**のWebP。周りの余白は切り詰め、解像度は表示したい高さの1.25倍くらい）
2. `_data/chara.yml` のそのキャラクターの `images` にファイル名を1行書き足して、コミットする

```
- name: 教師
  height: 380
  images:
    - teacher-normal.webp
    - teacher-smile.webp
```

- 表情を増やすときは `images` に1行足すだけ。新しいキャラクターは `- name:` から同じ形で書き足す
- キャラクターが4人以上いるときは、毎回その中から3人が選ばれる
- `height` は画面上の高さ（px）。今の3人は縮尺がそろうように、教師380px・キア383px・ポーラ301px にしています
- 表示する場所を変えるときは、`index.html` の最後にある `SLOTS` を書き換える
- ダウンロード対策：このリポジトリは公開されていて、サイト上の画像も取得できるため、キャラクター画像は透過させずに白背景へ焼き込み、解像度も控えめにしています（サイトの背景が白なので見た目は変わりません）。元の透過PNGや高解像度の画像は、このリポジトリに入れないでください

## 注意

- `title` や `name` に半角の `:` を入れるときは、全体を `"…"` で囲む
- `index.html` の先頭にある `---` の2行は消さない（お知らせが表示されなくなります）
